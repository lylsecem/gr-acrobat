# GR Acrobat

离线 PDF 软件：查看 PDF 和图片、转换（PDF 转图片、图片转 PDF）、合并拆分、打印。龙禹良制作。

全程在本机运行，不联网、不上传文件。支持 Windows 10 和 Windows 11。

## 安装

在 [Releases](https://github.com/lylsecem/gr-acrobat/releases/latest) 下载：

- 64 位 Windows（绝大多数电脑）：`GR-Acrobat-Setup-版本号-x64.exe`
- 32 位 Windows 10（部分旧电脑）：`GR-Acrobat-Setup-版本号-ia32.exe`

不确定是哪种：设置 → 系统 → 关于 →「系统类型」。装错了安装程序会提示。

如果电脑上装过「PDF 工作台」，安装时会自动把它卸载。

安装时可以勾选「开机后台预加载」，旧电脑、机械硬盘推荐勾上（见下文）。

## 自动更新

程序打开后约 8 秒、以及运行中每隔 6 小时，会到 GitHub（`lylsecem/gr-acrobat` 的 Releases）检查有没有新版本。
有的话右下角提示「发现新版本」，点「立即更新」：自动下载并校验，然后安装。Windows 会询问一次管理员权限，
点「是」；程序会自动关闭，装好后重新打开。没联网时不提示，也不影响使用。

覆盖安装会沿用原来「开机后台预加载」的设置。左下角显示当前版本号。

## 文字识别（可选）

把扫描版 PDF 变成能搜索、能复制文字的 PDF（页面看起来完全不变，只是多了一层看不见的文字），或者把文字导出成 TXT。
支持简体中文、英文和泰文，可以同时勾选几种（勾得越多越慢）。

- **可选安装**：第一次打开（或更新到 2.0.4 后）会询问要不要安装；也可以随时在左下角「文字识别」安装或移除。
  没安装时程序里没有这个功能，和以前完全一样。
- **不影响打开速度**：识别组件只在点「开始识别」时才加载；实测装与不装，打开程序到显示第一页的时间相同。
- **下载约 17 MB**：Tesseract 识别引擎（tesseract.js 7.0.0，Apache 2.0）和中、英、泰三种语言的识别数据，从 jsDelivr
  下载（不通时改用 unpkg），每个文件都核对大小和校验值。存放在 `%APPDATA%\gr-acrobat\ocr`，不需要管理员权限，
  卸载程序时一起删除。识别全程在本机进行，不上传文件。
- **用法**：打开 PDF →「文字识别」→ 在左边勾选页面（不选就识别全部）→ 选语言和输出 →「开始识别」。可以随时停止。
- **准确度**：清晰的印刷字识别得好；生僻字、手写字、模糊或倾斜的扫描件会有错字。

## 设为默认 PDF 程序

安装完成页勾选「打开默认应用设置」，或者自己打开 **设置 → 应用 → 默认应用**，搜索
「GR Acrobat」，把 `.pdf` 的打开方式改成它。

> Windows 10/11 不允许任何程序在安装时自动把自己设为默认，必须由你在设置里确认一次。

## 资源管理器里的 PDF 缩略图

GR Acrobat 是默认 PDF 程序时，资源管理器用「中等图标」「大图标」等视图看文件夹，PDF 的图标会显示成它的第一页，
左下角带 GR Acrobat 的小标记（加了密码或损坏的 PDF 仍显示普通图标）。

- 由一个小组件 `GRAcrobatThumbs.dll` 生成，用 PDFium（Chrome 浏览器的 PDF 引擎）画首页，只读取画首页需要的部分。
  Windows 在单独的进程里运行它，并把生成过的缩略图缓存起来，不影响 GR Acrobat 自己的打开速度。
- 装好后如果有的 PDF 还显示旧图标，在文件夹里按 F5 刷新；还不行就用「磁盘清理」清除「缩略图」。
- 资源管理器设置了「始终显示图标，从不显示缩略图」时不会显示。
- 32 位版本装在 64 位 Windows 上时没有这个功能（资源管理器是 64 位的）。

## 右键菜单

**在资源管理器里右键 PDF 文件** →「GR Acrobat」子菜单：

- 打开
- 合并所选文件（多选几个 PDF 再右键，它们会一起进入「合并拆分」）
- 拆分页面（在「合并拆分」里打开并展开这份文档）
- 转为图片（弹出「PDF 转图片」的选择窗口）
- 打印
- 合并打印（多选几个 PDF 再右键：按文件名顺序一起打印，和资源管理器按名称排列时的顺序一样，直接弹出选择打印机的窗口）

**右键图片**（jpg、png 等）→「用 GR Acrobat 转为 PDF」，多选的图片按文件名顺序合成一个 PDF（先弹出保存窗口）。
图片的「打开方式」里也有 GR Acrobat，可以直接看图片（也可以在 设置 → 应用 → 默认应用 里把它设为看图程序）。

Windows 11 的右键菜单默认是精简版，这些项目在「显示更多选项」里（或按 Shift+F10）。
要放进精简版的第一层，程序必须做成带数字签名的商店包（MSIX），普通安装程序做不到。

**在程序里右键**：

- 页面和缩略图：打印此页、把此页导出为 PDF 或图片、适合页面 / 宽度、加入合并拆分
- 页面上方的文档标签：关闭、关闭其他文档、全部关闭
- 合并拆分里的页面：预览、旋转、只导出所选、拆分成新文档、打印所选、收起文档、删除
- 合并拆分里的文档堆叠和左侧文档名：展开 / 收起、整份旋转、只导出、打印、移除

## 打开速度

- **大文件按需读取**：超过 8 MB 的 PDF 先只读取显示第一页所需的部分。常见的 PDF（Word、
  Acrobat、扫描仪、浏览器导出的）通常只需读一两 MB，几百 MB 的文件也能马上看到第一页。
  少数页面列表分散在整个文件里的 PDF，程序会自动改为一次顺序读完，这是机械硬盘上最快的读法。
- **启动时并行读文件**：双击 PDF 后，程序一边启动一边就开始读文件。
- **PDF 解析放在后台线程**：翻页、滚动缩略图时界面不卡。
- **导出功能延后加载**：拆分、合并用的组件在空闲时才加载，不拖慢打开。
- **开机后台预加载**（可选）：登录 Windows 后程序在后台静默启动并停在托盘，以后双击 PDF
  不用再等程序启动。约占 100 MB 内存。可以在程序左下角随时开关；关闭窗口时程序留在托盘，
  在托盘图标上右键「退出」才会真正退出。

## 功能

**查看**：打开即显示整页，可切换适合宽度；缩略图滚到才渲染。可以把 PDF 直接拖进窗口。

**同时打开多个文档**：每打开一个 PDF 或图片，页面上方就多一个标签，点标签切换，每个文档记住自己看到的页码和缩放。
不需要的点标签上的 ×（或中键点标签、Ctrl+W）关闭；Ctrl+Tab 切换到下一个。已经打开的文件再打开一次，只是切换过去。
一次可以选择或拖进多个文件。开着「开机后台预加载」时，关闭窗口也会关掉所有文档。

**看图片**：直接打开 JPG、PNG、GIF、BMP、WebP 图片（双击、「打开方式」、拖进窗口或 Ctrl+O），不用另装看图软件。
可以缩放、拖动、打印，也能「加入合并拆分」和别的 PDF 合在一起。
鼠标滚轮或 ↑ ↓ 键翻页：页面放大后先在页内滚动，到页底（页顶）再翻到下一页（上一页）；触控板滑一下翻一页。
按住 Ctrl 滚动滚轮缩放，以光标处为中心，最大 400%；触控板双指捏合也可以。
页面放大后，光标在页面上变成手掌，按住左键拖动就能移动页面（像 Photoshop 的抓手工具，不用按空格）。

**界面语言**：程序左下角可以切换 中文、English、ไทย，会记住选择；第一次打开时跟随 Windows 的显示语言（中文、泰文，其他语言用英文）。右键菜单的文字由安装程序按 Windows 的显示语言写入（中文、泰文，其他语言用英文）；安装程序本身是中文。

**有密码的 PDF**：打开时输入密码即可（密码不对会请你重新输入）。查看、打印、转换、合并拆分、
文字识别都能用；从它导出的新 PDF 不带密码。只限制打印、复制的 PDF 不用输入密码。

**转换**：左边「图片转 PDF」，右边「PDF 转图片」，把文件拖进对应的框（或点框选择）。

- **图片转 PDF**：拖进一张或多张图片，马上弹出 Windows 的保存窗口（默认在第一张图片所在的文件夹），
  选好位置和名字就开始生成。图片按文件名顺序每张一页（`扫描2` 排在 `扫描10` 前面）；页面大小可以在框里选
  「贴合图片尺寸」或 A4 竖向 / 横向。生成后可以直接「打开」它。
- **PDF 转图片**：拖进 PDF，弹出一个小窗口选择图片格式（PNG / JPEG）、清晰度（1x–4x）、页面（全部或页码范围）
  和保存位置（默认是 PDF 所在的文件夹，「更改…」可以另选），点「开始转换」。每页直接存成一张图片，不打包：
  只转一页时存在所选位置，多页时存在那里新建的「原名_图片」文件夹里（`TRUCKOEM_图片\TRUCKOEM_第1页.png`……）。
  已有的文件不会被覆盖（同名时自动加「 (2)」）。转完可以点「打开文件夹」直接看到。

也可以在资源管理器里右键 PDF「转为图片」、右键图片「用 GR Acrobat 转为 PDF」，同样进入这两个流程。
查看时右键页面或缩略图「把第 n 页导出为图片」，会直接存在原文档旁边。

**合并拆分**（参考 Acrobat 的「组织页面」）：每份 PDF 先叠成一摞，用原文件名命名；悬停「展开」
查看每一页，首页上的「收起」叠回去；单页或整摞都能拖动排序、旋转、删除，Ctrl+Z 撤销，
最后「合并并下载」成一个文件。

拆分：选中页面（Ctrl 或 Shift 点选多页），拖到左侧的文档栏，就生成一份新文档，存在原文档所在的文件夹，
名字是原名加编号：`TRUCKOEM.pdf` 拆出 `TRUCKOEM_1.pdf`、`TRUCKOEM_2.pdf`……，已有的文件不会被覆盖。
新文档出现在文档栏里。随后会问原文档里的这些页「删除」还是「保留」：删除就改写原文件，只留下其余的页面；
保留则原文件不变。也可以右键所选页面「拆分成新文档」。

**打印**（Ctrl+P）：全部、当前页 / 所选页面或自定义范围；清晰度 150 / 200 / 300 dpi；
横向页面可自动旋转铺满纸张。

快捷键：Ctrl+O 打开，Ctrl+W 关闭文档，Ctrl+Tab 切换文档，Ctrl+P 打印，↑ ↓ 翻页，Ctrl+滚轮 缩放，左键拖动 移动放大的页面，Delete 删除所选，Ctrl+Z 撤销，Esc 关闭菜单或预览。

## 界面

按 taste-skill 的应用界面规则设计：左侧浅色框架放导航，工作内容在白色底板上，页面放在略深
一级的底色里；颜色只用在选中状态和文档标识上。跟随系统的浅色 / 深色模式。

## 开发

需要 [Node.js](https://nodejs.org/)（LTS 版本）。

```
npm ci            # 安装依赖
npm start         # 运行程序；环境变量 GR_PERF=1 会在终端打印启动和打开文件的耗时
npm test          # 端到端测试（另需 Python，见 tests/README.md）
npm run dist      # 在 dist\ 生成 64 位、32 位两个安装包和 latest.json
```

Windows、macOS、Linux 上都能编译安装包，不需要 Wine。测试说明见 [tests/README.md](tests/README.md)，
给 Claude Code 的项目说明见 [CLAUDE.md](CLAUDE.md)。每次推送到 GitHub，Actions 会自动跑一遍测试。

### 发布新版本

已安装的程序会自动提示更新（它读取最新正式版里的 `latest.json`）。

1. 改 `package.json` 里的 `version`
2. 写这次的更新说明：`build/release-notes.txt`（中文），`release-notes.en.txt`、`release-notes.th.txt`（英文、泰文；
   没有就显示中文）。程序的更新提示里显示的就是这些文字
3. 提交并推送，然后推送版本标签：

   ```
   git tag v3.0.1
   git push origin v3.0.1
   ```

   GitHub Actions 会先跑测试，再打包两个安装包和 `latest.json`，发布为**正式版**（不是 pre-release）并设为最新版。

也可以手动发布：`npm run dist`，在 GitHub 新建 Release（标签 `v版本号`），上传 `dist` 里的两个安装包和
`latest.json`；**不要勾选「Set as a pre-release」**，保持勾选「Set as the latest release」。

## 项目结构

```
main.js                 主进程：单实例、启动参数和右键菜单动作、按需读文件、托盘与开机预加载、打印、检查更新
preload.js              安全桥接：页面只能读取由启动动作交给它的文件
index.html              界面和全部功能
vendor/                 pdf.js / pdf-lib 和 IBM Plex Sans 字体，离线可用
icon.ico                程序图标
build/afterPack.js      给 exe 写入图标和「龙禹良制作」发布者信息
i18n.js                 界面的英文、泰文文字（页面用中文写，按中文原文查找译文）
build/release-notes.txt 这一版的更新说明（显示在程序的更新提示里）；release-notes.en.txt / .th.txt 是英文、泰文版
build/thumbs/           用 PDFium 的两个小组件：资源管理器缩略图 GRAcrobatThumbs.dll，和给有密码的 PDF
                        生成无密码副本的 GRAcrobatUnlock.exe。src/ 源码，x64/ ia32/ 编好的文件和 pdfium.dll，
                        build.sh 用 MinGW 重新编译，make-badge.py 把左下角的标记 badge-preview.png 转成源码
build/installer.nsi     安装程序：PDF 和图片的文件关联、右键菜单、开机预加载、卸载旧版、卸载
build/make-installer.js 编译 64 位和 32 位安装程序，生成 latest.json
tests/                  端到端测试（驱动真实程序）、测试文件生成、Windows 组件测试
.github/workflows/      推送时跑测试；推送版本标签时打包并发布
```
