3.1.2
- เพิ่ม “รวมแล้วพิมพ์” ในเมนูคลิกขวา: เลือก PDF หลายไฟล์ในโฟลเดอร์ คลิกขวาแล้วเลือกเมนูนี้ ไฟล์จะพิมพ์ต่อกันตามลำดับชื่อไฟล์ (เหมือนที่ File Explorer เรียงตามชื่อ) และเปิดหน้าต่างเลือกเครื่องพิมพ์ทันที
- เมนูคลิกขวาใน File Explorer (เปิด รวมไฟล์ที่เลือก แยกหน้า แปลงเป็นรูปภาพ และพิมพ์ ในเมนู “GR Acrobat” และ “แปลงเป็น PDF ด้วย GR Acrobat” บนรูปภาพ) และชื่อประเภทไฟล์ จะแสดงตามภาษาของ Windows: ภาษาจีนบน Windows ภาษาจีน ภาษาไทยบน Windows ภาษาไทย และภาษาอังกฤษบน Windows ภาษาอื่น
